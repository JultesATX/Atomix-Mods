Title cards in the style of Sonic Mania.

About the Mod

Sonic Mania Title Cards transforms the way zones are introduced in Sonic 3 AIR. Enjoy beautifully recreated animations, custom banners, and authentic sound aesthetics inspired by Sonic Mania, adding a polished, modern touch to your classic playthroughs.

How do I make my MISC character compatible with this mod?

Okay, for that, in the Helper Functions script you should see something like this:

//Tested only on level results (still doesn't work well on special stages)
function string getCharacterResultsNameplate(u8 character)
{
    // example, change to your own slot
    if MISC.player1.character == CHARACTER_GOKU //script default
        return "result_nameplate_char69"
    return base.getCharacterResultsNameplate(character)
}

Simply replace GOKU with your character and in new condition add the name of the new sprite, leaving the one below intact.

function string getCharacterResultsNameplate(u8 character)
{
    // example, change to your own slot
    if (MISC.player1.character == CHARACTER_GOKU && Mods.isModActive("sm-title-cards")) //new condition
        return "result_nameplate_Goku_Mania"
    else if MISC.player1.character == CHARACTER_GOKU //script default
        return "result_nameplate_char69"
    return base.getCharacterResultsNameplate(character)
}
